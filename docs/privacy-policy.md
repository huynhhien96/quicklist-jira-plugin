# Privacy Policy for Quick List

**Last updated:** June 29, 2026

## Overview

Quick List is a Jira issue panel app built on the Atlassian Forge platform. This Privacy Policy explains what data the app collects, how it is stored, and how long it is retained.

## Data Collected

Quick List collects only the data that users explicitly enter within the app:

- Task summaries
- Task statuses (To Do / Done)
- Task notes

No personal data, user identifiers, account information, or usage analytics are collected.

## Data Storage

All data is stored exclusively within **Atlassian Forge Storage**, which is infrastructure managed and operated by Atlassian. Data is stored per Jira issue and is accessible only within the context of that issue.

Quick List does not transmit any data to external servers or third-party services.

## Data Retention

Stored data is automatically deleted after **90 days of inactivity** (i.e., if the panel has not been opened for 90 consecutive days). Users may also remove individual tasks or all tasks at any time using the controls within the panel.

## Data Sharing

Quick List does not share any data with third parties. All data remains within the Atlassian platform under the data governance policies of your Atlassian organization.

## User Rights

Users may delete their data at any time by removing tasks from the panel. If you require complete data removal from Forge Storage, please contact your Atlassian site administrator.

## Changes to This Policy

If this Privacy Policy is updated, the "Last updated" date above will be revised. Continued use of the app after any changes constitutes acceptance of the updated policy.
